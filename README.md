## About BDW Portal

Track teachers lesson progress initialized by coordinator.

- [BDWInTernational School](https://bdwinternationalschool.com/).


## Steps to start up the portal

- Rename database from config.php and .env file
- run `composer update` command
- run `php artisan migrate:fresh` for vite
- run `npm run dev` for vite
- run `php artisan serve` command
